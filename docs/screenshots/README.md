# Screenshots

This folder is a placeholder for project screenshots to include in your
submission or report. After running the app locally (see the main README),
take screenshots of these pages and save them here with these filenames:

- home.png                 – Home page (index.html)
- tournaments.png          – Tournament listing with search/filter/pagination
- tournament-details.png  – Tournament details page
- create-tournament.png   – Create tournament form
- registrations.png       – Organizer approving/rejecting players
- matches.png             – Match scheduling & result entry
- leaderboard.png         – Leaderboard page
- results.png             – Published tournament results
- dashboard-organizer.png – Organizer dashboard
- dashboard-player.png    – Player dashboard
- profile.png             – Profile page

Tip: use your browser's full-page screenshot feature (or the "Live Server" +
browser DevTools device toolbar) to capture clean, consistent screenshots for
your project report or PPT.
